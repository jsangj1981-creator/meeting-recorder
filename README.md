# 🎙 미팅 녹음

외부 미팅을 **아이폰으로 녹음**하고, 끝나면 **연자 1·2·3으로 자동 구분된 텍스트**로 바꿔
**Claude 앱에 붙여 넣어 정리**하는 홈 화면 웹앱입니다.

- 앱 아이콘을 누르면 **바로 녹음 시작**
- 녹음은 5초마다 휴대폰에 저장 → 앱이 꺼져도 그때까지의 녹음이 남음
- 녹음이 끊기면(전화, 앱 전환 등) 화면으로 돌아왔을 때 **자동으로 이어서 녹음**
- 녹음 중 **화면 꺼짐 방지** (iOS 18.4 이상)
- 종료 후 **텍스트 변환 (AssemblyAI, 연자 자동 구분)** → **Claude용 복사 / 공유**
- 녹음 파일과 기록은 **이 휴대폰에만 저장** (서버 없음)

---

## 처음 한 번만: 설정 방법

### 1. AssemblyAI API 키 만들기 (텍스트 변환용)
1. https://www.assemblyai.com 에서 가입합니다.
2. 대시보드의 **API Keys**에서 키를 복사해 둡니다.
3. 사용한 만큼 요금이 나옵니다. 최신 요금은 AssemblyAI 요금 페이지에서 확인하세요.

> ⚠️ 고객사 미팅 음성이 AssemblyAI(해외 서버)로 전송됩니다. **회사 보안 기준을 먼저 확인**하세요.
> 앱은 변환 결과를 받은 뒤 AssemblyAI 서버의 변환 기록 삭제를 요청합니다.

### 2. 앱을 인터넷 주소(https)에 올리기: GitHub Pages
1. GitHub Desktop에서 **File → New repository**를 누르고, 이름을 `meeting-recorder` 등으로 정합니다.
2. 이 폴더의 파일을 **모두** 저장소 폴더에 복사합니다.
   - `index.html`, `style.css`, `app.js`, `store.js`, `transcribe.js`, `sw.js`, `manifest.webmanifest`, `icons/`
3. **Commit**한 뒤 **Publish repository**를 누릅니다. 이때 *Keep this code private*는 **해제**합니다(무료 Pages는 공개 저장소만 가능).
4. github.com에서 저장소로 들어가 **Settings → Pages**를 엽니다. Branch를 `main` / `(root)`로 고르고 **Save**를 누릅니다.
5. 1~2분 뒤 `https://<GitHub아이디>.github.io/meeting-recorder/` 주소가 생깁니다.

> 공개되는 것은 앱 코드뿐입니다. API 키, 녹음 파일, 미팅 기록은 휴대폰에만 저장되어 공개되지 않습니다.

### 3. 아이폰에 앱처럼 설치
1. 아이폰 **Safari**로 위 주소를 엽니다. Chrome에서는 홈 화면 앱 설치가 되지 않습니다.
2. 하단 **공유 버튼(□↑) → 홈 화면에 추가 → 추가**를 누릅니다.
3. 홈 화면의 **미팅녹음** 아이콘으로 실행합니다.
4. 마이크 권한 창이 뜨면 **허용**을 누릅니다.
5. 우측 상단 **설정**에서 AssemblyAI API 키를 붙여 넣고 **저장**합니다.
   - 처음 실행하면 바로 녹음이 시작되므로, **녹음 취소**를 누른 뒤 목록에서 설정하면 됩니다.

### 4. 마이크 권한을 매번 묻는 경우
iOS 홈 화면 앱은 실행할 때마다 마이크 권한을 다시 물을 수 있습니다(iOS 자체 동작). 다음과 같이 하면 줄어듭니다.
- **설정 → 앱 → Safari → 마이크 → "허용"**

## 사용 방법

1. **미팅 시작 전**: 아이폰을 **방해금지/집중 모드**로 바꿉니다. 전화가 오면 녹음이 끊길 수 있습니다.
2. 앱 아이콘을 누르면 **바로 녹음**이 시작됩니다. 휴대폰은 테이블 가운데에 두세요.
3. 녹음 중에는 **화면을 켜 둔 채** 두고 **다른 앱으로 넘어가지 마세요.**
   - 끊겼다면 앱으로 돌아오면 자동으로 이어서 녹음합니다. 이때 여러 구간으로 나뉘어 저장됩니다.
4. **종료**를 누르면 미팅 화면으로 이동합니다. 제목은 눌러서 바꿀 수 있습니다.
5. **참석 인원**을 고르고(알면 더 정확) **텍스트 변환 시작**을 누릅니다. 앱을 닫아도 다시 열면 이어서 확인합니다.
6. 변환이 끝나면 **Claude용 복사**를 누릅니다. Claude 앱에 붙여 넣으면 정리 요청 문구와 미팅 기록이 함께 들어갑니다.
   - **공유**를 누르면 텍스트 파일로 Claude 앱 등에 바로 보낼 수 있습니다.
   - 정리 요청 문구는 **설정**에서 바꿀 수 있습니다.
7. 원본 녹음은 **음성 파일 저장/공유**로 '파일' 앱 등에 백업할 수 있습니다.

> 녹음 목록만 보고 싶을 때: 앱이 이미 실행 중이면 마지막 화면이 그대로 열립니다.
> 앱을 새로 열면 녹음이 시작되므로 **녹음 취소**를 누르면 됩니다. **설정**에서 자동 시작을 끌 수도 있습니다.

## 파일 구조

```
index.html            # 화면 (녹음 / 권한 안내 / 목록 / 미팅 상세 / 설정)
style.css             # 스타일 (바이오메드 화이트+연두 팔레트)
app.js                # 녹음, 끊김 복구, 화면 꺼짐 방지, 변환 진행, 내보내기
store.js              # 휴대폰 내 저장 (IndexedDB)
transcribe.js         # AssemblyAI 연동 (업로드 → 변환 → 연자 구분 결과)
sw.js                 # 오프라인 실행용 서비스 워커
manifest.webmanifest  # 홈 화면 앱 정보
icons/                # 앱 아이콘
```

## 알려진 제한 사항

- iOS 홈 화면 웹앱은 **화면을 잠그거나 다른 앱으로 전환하면 녹음이 멈출 수 있습니다.** 앱으로 돌아오면 자동으로 이어서 녹음합니다.
  화면을 잠근 상태로 녹음해야 한다면 네이티브 앱(Apple 개발자 계정 필요)이 필요합니다.
- 연자 구분은 AI가 목소리로 추정한 것이라 틀릴 수 있습니다. 녹음이 여러 구간으로 나뉘면 구간마다 연자 번호가 따로 매겨집니다.
- 텍스트 변환에는 인터넷이 필요합니다. 녹음 자체는 인터넷 없이도 됩니다.
- 녹음은 휴대폰 저장 공간을 사용합니다(1시간에 약 30MB). 오래된 미팅은 백업 후 삭제하세요.
- 네이버 CLOVA Speech는 브라우저에서 직접 호출할 수 없어(CORS 차단) 중계 서버가 필요합니다. 회사 결정 후 추가할 수 있습니다.

## 업데이트 방법

파일을 수정한 뒤 GitHub Desktop에서 **Commit → Push**합니다. 아이폰에서 앱을 **두 번 다시 열면** 새 버전이 반영됩니다.
